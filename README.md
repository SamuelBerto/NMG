
# 🧠 Nice Memory Game

Um jogo da memória desenvolvido com HTML, CSS e JavaScript puro, com visual pixel art, ranking, cronômetro e efeitos sonoros.

---

## 🎮 Sobre o projeto

O **Nice Memory Game (NMG)** foi criado para praticar desenvolvimento web front-end e lógica de programação utilizando JavaScript puro.

O projeto evoluiu ao longo do desenvolvimento, recebendo novas funcionalidades e melhorias visuais para simular um projeto real de portfólio.

Atualmente o jogo possui:

- Sistema de login
- Ranking local
- Cronômetro
- Sons interativos
- Botão de reinício
- Interface estilo retrô/pixel art
- Armazenamento com LocalStorage

* Virar cartas
* Acertar pares
* Vitória
* Reiniciar partida

---

## 🕹️ Como jogar

1. Digite seu nome
2. Clique em "Jogar"
3. Encontre todos os pares de cartas
4. Tente finalizar com:

   * Menor número de jogadas
   * Menor tempo possível
